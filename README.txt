# CKD SEPA GiroCode v4.1

## O que mudou
- Mantém o layout da v4.
- ADM com abas.
- Aba QR Code com pré-visualização antes de salvar.
- Controles independentes para:
  - tamanho do logo
  - tamanho do círculo branco
  - espessura da borda cinza
  - transparência da borda
  - intensidade da sombra
  - desfoque da sombra
  - distância da sombra
- Botões Cancelar, Aplicar e Salvar na pré-visualização.
- Importar e exportar config.js.

## Acesso ao ADM
Clique 5 vezes no logo CKD.

Senha padrão:
CKD2025

## Atualizar no GitHub Pages
1. Extraia este ZIP.
2. Abra seu repositório CKD-SEPA no GitHub.
3. Clique em Add file > Upload files.
4. Envie todos os arquivos extraídos.
5. Substitua os arquivos antigos.
6. Clique em Commit changes.
7. Aguarde 1 a 3 minutos.
